# Bound retained draft-window graphs during ordinary decoding

A model with an attached DSpark head records a bounded hidden-state tail even while a later request selects AR. Joining and slicing tail chunks bounded their visible row count, but the unevaluated concatenation still retained the previous compacted tail and its forward graphs. Repeated compaction could therefore retain old tensors and Metal events for the duration of a long AR response.

Compaction now schedules the bounded rows with `asyncEval` before retaining them. This detaches the old graph as evaluation is encoded, preserves the same rows, positions and rollback state, and introduces no host-side wait. It changes neither sampling nor output limits, and does not discard the hidden state needed by a later Adaptive request. The change applies to the shared tail used by DeepSeek-V4.1 and MiniMax-M3.

The current combined app exposed a Metal shared-event allocation failure after a 1,636-token AR response following Adaptive turns. A source regression confirms the retained lazy graph; it fails on the landed runtime and passes with this change. All 37 focused tests pass, including a 4,096-step GPU control that records unread hidden taps, long CPU history/rollback, sampled and greedy speculative parity, and draft-window/cache contracts. Another 48 tests across six related MiniMax/cache suites pass. These are separate retained runs, not one combined test invocation. A simple separate 20,000-step GPU scalar control passed without reproducing the model failure.

The full-app event failure is preserved separately and remains under verification until the rebuilt app completes the affected long AR flow. Earlier normal DSV tool, cache, cancellation/recovery and fresh-chat rows remain accepted within their scope. A native sampled Adaptive code row completed at 33.0 tokens/s with passing generated tests and 130 independent input checks; this is not a 60 tokens/s claim or a valid speedup against the failed AR row. No model defaults or behavior guards are changed, and no release is requested.
